# UASE Aviation Command Center - File Management Update

## الملفات داخل الحزمة
- `main.py`: خادم المنصة مع واجهات رفع وعرض وإعادة تسمية وحذف الملفات.
- `requirements.txt`: المتطلبات، ويشمل `python-multipart` لرفع الملفات.
- `static/index.html`: واجهة المنصة بعد إضافة مكتبة ملفات مستقلة لكل مادة.

## ما تمت إضافته
- عرض ملفات كل مادة داخل صفحة المادة.
- رفع ملفات محاضرات وصور من لوحة الإدارة فقط.
- إعادة تسمية الملف وحذفه من لوحة الإدارة.
- فتح وتنزيل الملفات للطلاب.
- معاينة الصور داخل صفحة المادة.
- الحد الأعلى للملف الواحد 30 MB.
- أنواع الملفات المقبولة: PDF والصور الشائعة وملفات Office وTXT وZIP وMP4.

## النشر على Railway
استبدل الملفات التالية في مستودع GitHub:
1. `main.py`
2. `requirements.txt`
3. `static/index.html`

اترك بقية ملفات مجلد `static` الموجودة حالياً كما هي، خصوصاً `telegram-web-app.js`.

## تخزين الملفات
يحفظ التطبيق الملفات داخل `DATA_DIR/uploads`، وقاعدة البيانات داخل `DATA_DIR`.
حتى تبقى الملفات بعد إعادة إنشاء الحاوية أو إعادة النشر، يجب أن يكون لدى خدمة Railway Volume مركّب على المسار `/data` (وهو المسار الافتراضي المستخدم في إعدادات هذا المشروع).

## ملاحظة عن زر البوت والرسالة الواحدة
هذه الحزمة تعدّل المنصة الأكاديمية (FastAPI وواجهة Mini App). جعل قوائم بوت Button Manager تتنقل بتعديل رسالة Telegram نفسها يحتاج تعديل كود البوت المنفصل، ولم يكن ضمن الملفات المرفوعة لهذه الحزمة.
