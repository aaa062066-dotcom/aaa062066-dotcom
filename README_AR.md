# UASE | Aviation Command Center
نسخة أولى: Telegram Mini App لفهرس المواد والمختبرات والجدول والمصادر.

## مهم قبل النشر
هذا المشروع هو خادم Mini App مستقل، وليس نسخة ثانية من برنامج استقبال رسائل البوت.
لا يشغّل polling ولا webhook ولا يستولي على تحديثات البوت. يستخدم BOT_TOKEN للتحقق من جلسة Telegram ولضبط زر Menu Button عبر Bot API.
بهذا تستطيع إبقاء كود البوت الحالي يعمل على استضافته الحالية.

إذا كان زر القائمة مخصصاً حالياً لغرض آخر، فإن تشغيل إعداد الزر سيستبدله بزر Open Student Portal. يمكنك حذف WEBAPP_URL مؤقتاً لمنع هذا التغيير.

## الملفات
- `main.py`: FastAPI backend، التحقق من Telegram initData، قاعدة SQLite، API الإدارة، إعداد زر القائمة.
- `static/index.html`: واجهة الهاتف العربية/الإنجليزية.
- `requirements.txt`: الاعتماديات.
- `Dockerfile`: بناء الحاوية.
- `railway.toml`: إعداد تشغيل Railway.
- `.env.example`: أسماء متغيرات البيئة.

## النشر المقترح على Railway
1. أنشئ Repository خاصاً على GitHub وارفع محتويات هذا المجلد إليه.
2. في Railway اختر New Project ثم Deploy from GitHub Repo.
3. افتح الخدمة ثم Settings > Networking > Generate Domain للحصول على رابط HTTPS.
4. أضف Volume إلى الخدمة واجعل Mount Path هو `/data`.
5. أضف Variables:
   - `BOT_TOKEN` = توكن البوت الموجود لديك. لا ترسله في المحادثة ولا تضعه داخل الكود.
   - `WEBAPP_URL` = رابط HTTPS الذي أعطاك Railway، مثال `https://your-app.up.railway.app`
   - `ADMIN_IDS` = رقم حساب تيليجرام الخاص بك. يمكن وضع أكثر من رقم مفصولاً بفاصلة.
   - `DATA_DIR` = `/data`
6. أعد النشر. عند بدء الخدمة، يحاول الخادم إعداد زر قائمة البوت باسم `Open Student Portal`.
7. افتح البوت من حسابك واضغط زر القائمة. يجب أن تفتح الواجهة داخل تيليجرام.

ملاحظة: يضبط الخادم زر القائمة تلقائياً فقط عندما يكون `BOT_TOKEN` و`WEBAPP_URL` موجودين ويبدأ الرابط بـ HTTPS. لا يحتاج إلى تشغيل polling، ولا يتعارض مع polling الموجود في برنامج البوت الحالي.

## كيف تعرف Telegram User ID؟
افتح البوت من حسابك ثم استخدم بوتاً موثوقاً يعرض رقم Telegram ID، أو أضف طريقة عرض ID في بوتك الحالي. ضع الرقم في `ADMIN_IDS`.
لا تستخدم username بدلاً من الرقم.

## إدارة المحتوى
بعد إدراج Telegram ID في `ADMIN_IDS` وإعادة النشر:
1. افتح Mini App من داخل تيليجرام.
2. سيظهر قسم `لوحة إدارة المحتوى`.
3. يمكنك تعديل روابط المواد والمختبرات والجدول والمصادر.
4. لإضافة عنصر، اختر إضافة قسم جديد، واستخدم معرّفاً إنجليزياً صغيراً مثل `new-subject`.
5. الروابط يجب أن تكون HTTPS.

المحتوى الافتراضي:
- 6 مواد نظرية.
- مختبران.
- قسم جدول المحاضرات (أضف رابط صورة أو PDF أو صفحة جدول).
- رابط مجلد Google Drive المقدم.

## قاعدة البيانات والنسخ الاحتياطي
- تحفظ البيانات في `/data/uase.db`.
- لا تحذف Volume ولا تغيّر مسار `/data` بعد بدء الاستخدام.
- خذ نسخة احتياطية من `uase.db` قبل أي تغييرات بنية مستقبلية.
- هذه قاعدة مستقلة تماماً ولا تستخدم قاعدة Hard Study.

## اختبار محلي
Python 3.11+:
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
```
ضع المتغيرات في البيئة، ثم:
```bash
uvicorn main:app --host 0.0.0.0 --port 8000
```
للاختبار داخل Telegram يجب أن يكون WEBAPP_URL عنوان HTTPS عاماً، وأن تفتح Mini App من البوت. فتح الصفحة مباشرة في المتصفح لن يوفر initData صالحاً.

## حدود النسخة الأولى
- لا يوجد رفع ملفات إلى الخادم؛ الروابط تشير إلى Google Drive أو منشورات/ملفات خارجية.
- لا يوجد بحث داخل محتوى PDF، البحث الحالي في أسماء العناصر وأوصافها.
- الواجهة تتطلب فتحها من Telegram لأن جلسة Mini App يتم التحقق منها على الخادم.
- لا تضع BOT_TOKEN في HTML أو JavaScript أو GitHub.
